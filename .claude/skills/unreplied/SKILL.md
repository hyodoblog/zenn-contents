# 未返信アラート

チャネルの会話を分析し、返信漏れ・対応漏れを検知してLINEに通知する。

## 引数

`$ARGUMENTS` は以下の形式で受け取る:

- 引数なし — 全LINEチャネルを対象に直近3日間をチェック
- `[チャネル名]` — 特定チャネルのみチェック
- `[期間]` — 期間指定（例: `1週間`、`5日`）
- `[チャネル名] [期間]` — 両方指定

## 実行手順

### Step 1: 対象チャネルの取得

1. `list-channels` でチャネル一覧を取得（type: "LINE"）
2. チャネル名指定がある場合はキーワードで絞り込む
3. 指定がない場合はアクティブな全チャネルを対象

### Step 2: 各チャネルのメッセージ取得

各チャネルに対して `list-messages` を実行:
- デフォルト期間: 直近3日間
- `senderType` フィルタは使わず全メッセージを取得（会話の流れを見るため）

### Step 3: 未返信の判定

以下のパターンで未返信を検知する:

#### パターン1: ユーザーからの質問に未回答
- USER発のメッセージが最後で、その後BOT/AIの返信がない
- 特に「？」「でしょうか」「ですか」「お願い」「教えて」を含むメッセージ

#### パターン2: 会話の途絶
- ユーザーのメッセージから24時間以上経過し、返信がない
- ただし挨拶（「ありがとう」「了解」等）で終わっている場合は除外

#### パターン3: 明示的な依頼への未対応
- 「〇〇してほしい」「〇〇をお願い」「確認お願い」等の依頼表現
- その後に対応完了を示すメッセージがない

### Step 4: 未返信リストの整理

検知した未返信を以下の情報で整理する:

1. **チャネル名**: どのチャネルか
2. **送信者名**: 誰からのメッセージか
3. **メッセージ抜粋**: 元のメッセージの要約（30文字以内）
4. **経過時間**: 何時間/何日前か
5. **緊急度**: 高（48時間超）/ 中（24〜48時間）/ 低（24時間未満）
6. **推奨アクション**: どう返信すべきかの提案

### Step 5: 送信先の特定

1. `list-connect-users` でLINEユーザー一覧を取得（type: "LINE"）
2. 送信先をユーザーに確認する（**必ず確認してから送信すること**）

### Step 6: LINEへ配信

`send-line-message` でFlexメッセージとして送信する。

#### メッセージフォーマット

**未返信がある場合:**
```json
{
  "type": "flex",
  "altText": "未返信アラート: X件の対応漏れ",
  "contents": {
    "type": "bubble",
    "size": "giga",
    "header": {
      "type": "box", "layout": "vertical",
      "contents": [
        { "type": "text", "text": "未返信アラート", "weight": "bold", "size": "lg", "color": "#e74c3c" },
        { "type": "text", "text": "X件の対応漏れ | [チェック期間]", "size": "xs", "color": "#999999" }
      ]
    },
    "body": {
      "type": "box", "layout": "vertical", "spacing": "lg",
      "contents": [
        {
          "type": "box", "layout": "vertical", "spacing": "sm",
          "contents": [
            { "type": "text", "text": "[高] チャネル名 — 送信者名", "weight": "bold", "size": "sm", "color": "#e74c3c" },
            { "type": "text", "text": "「メッセージ抜粋...」(2日前)", "size": "xs", "wrap": true, "color": "#666666" },
            { "type": "text", "text": "→ 推奨: 〇〇と返信する", "size": "xs", "color": "#333333" }
          ]
        },
        { "type": "separator" }
      ]
    }
  }
}
```

**未返信がない場合:**
```json
{
  "type": "text",
  "text": "未返信チェック完了\n対応漏れはありません（[チェック期間]）"
}
```

## LLM出力ポリシー（厳守）

- **推奨アクションは具体的な返信文案**: 「返信する」→「『ご連絡ありがとうございます。〇〇の件、確認いたしましたので本日中にお返事いたします』と返信」
- **緊急度の判定基準を明確に**: 時間経過だけでなく、内容（クレーム・金額・期限付き依頼）も考慮
- **LINE表示前提**: 1件あたり3行以内、緊急度順にソート

## 注意事項

- 送信前に必ずユーザーに内容と送信先を確認すること
- BOT自動返信への返信漏れは除外する（人間の対応が必要なもののみ）
- 「スタンプのみ」「画像のみ」のメッセージは未返信判定の対象外
- 未返信が10件を超える場合は緊急度「高」のみに絞り、件数を報告
