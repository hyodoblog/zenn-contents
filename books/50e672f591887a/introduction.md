## 本カリキュラムの目的

本カリキュラムでは、LINE と Stripe を用いて自社で DB を持たず、Stripe のダッシュボードで顧客管理、商品管理、注文管理ができる、LINE チャットコマースアプリを作ります。

本カリキュラムを通して、以下のことを学びます。

- LINE Messaging API の基本的な使い方
- Stripe の基本的な使い方
- LINE と Stripe を組み合わせたアプリの作り方

## 本カリキュラムの前提条件

本カリキュラムを進めるにあたって、以下の知識があることを前提とします。

- Node.js の基礎知識
- Express の基礎知識
- Git の基礎知識
- API の基礎知識
- LINE Messaging API の基礎知識

## 本カリキュラムの対象者

本カリキュラムは、以下の方を対象としています。

- LINE と Stripe を組み合わせたアプリを作りたい方
- LINE と Stripe を組み合わせたアプリを作る際に、どのような構成にすれば良いか悩んでいる方
- LINE と Stripe を組み合わせたアプリを作る際に、どのような機能を実装すれば良いか悩んでいる方

## 本カリキュラムのゴール

本カリキュラムを終えることで、以下のことができるようになります。

- LINE と Stripe を組み合わせたアプリを作る際の構成を考えられるようになる
- LINE と Stripe を組み合わせたアプリを作る際の機能を考えられるようになる
- LINE と Stripe を組み合わせたアプリを作る際の実装方法を考えられるようになる
