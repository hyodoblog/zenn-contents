以上で DB を利用せず、Stripe のみで LINE 通販アプリを構築することができました。

本カリキュラムでは、Stripe の実践でよく使われる API の使い方を実例をもとに利用しており、実践的な内容となっています。

Stripe は、決済以外にも、顧客管理、請求書管理、サブスクリプション管理など、様々な機能を提供しています。

本カリキュラムを通して、Stripe の機能を理解し、実際に利用することで、決済アプリの開発をスムーズに進めることができるようになることを願っております。
