Claude CodeやCodexに作業をお願いして、移動している間も進めておいてほしい。

そのためにスマホからPCをリモート操作する方法もありますが、出発前に指示を出して、PCをスリープさせずに動かしておくだけでもよいのでは？と思いました。

途中で追加の指示が必要なければ、次にPCを開いたときに結果を確認できれば十分です。今回は、MacBook Airでそのために使う設定を紹介します。

## スリープを無効にする

ターミナルで以下を実行します。

```bash
sudo pmset disablesleep 1
```

Macのログインパスワードを求められたら入力します。入力中は文字が表示されませんが、そのまま入力してEnterを押せば大丈夫です。

`pmset`はmacOSの電源管理を変更するコマンドで、`disablesleep 1`はスリープを無効にする設定です。蓋を閉じても処理を続けたいときに使いますが、使うMacとmacOSで実際に処理が続くかは事前に確認してください。

なお、`-b`を付ければバッテリー駆動時だけに限定できる、というわけではありません。Appleが公開している実装では、`disablesleep`はシステム全体の設定として扱われています。

[参考：Appleのpmset実装](https://github.com/apple-oss-distributions/PowerManagement/blob/main/pmset/pmset.m)

設定の確認はこちらです。

```bash
pmset -g
```

`SleepDisabled`が`1`なら、スリープ無効の設定になっています。

## 終わったら元に戻す

```bash
sudo pmset disablesleep 0
```

使い終わったら戻しておきます。ターミナルを閉じるだけで解除する使い方ではないので、戻し忘れには注意してください。

## 移動中に使うときの注意

スリープを止めても、通信が切れたり、途中で確認や承認を求められたりすれば作業は待ち状態になります。Claude CodeやCodexを手元のMacで動かす場合は、テザリングなどの通信手段も必要です。

また、動かしている間はバッテリーを消費し、発熱もします。移動中でも、新幹線のテーブルなど通気のよい場所に置ける場面で使い、カバンへ入れる前には設定を戻してスリープさせてください。[Appleも通気のよい、安定した台の上で使うよう案内しています。](https://support.apple.com/ja-jp/102336)

移動中も細かく操作したいならリモート操作が便利ですが、お願いした作業を進めておいてほしいだけなら、この設定で足りる場面もありそうです。
