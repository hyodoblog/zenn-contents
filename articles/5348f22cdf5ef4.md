## 背景：取引先の悩みは“記事更新の手間とコスト”だった

今回の事例でご紹介する取引先は、**HP 制作からブログ＆コラム更新まで幅広く請け負う会社**さんです。クライアントも多いため、

- 毎月大量のブログやコラムを書かなければならない
- 担当者がライターのチェックや編集に追われっぱなし
- CMS への投稿や画像のアップロードなど細かい作業が山積み

といった状態が続き、**人件費がどんどん膨らむ**という悩みを抱えていました。  
そこで「AI を使って、もっと効率よく更新できる方法がないだろうか」という相談をいただいたんです。

## 解決策：独自プロンプト＋自動反映ツールを一体化

### 独自プロンプトの開発

ChatGPT は便利ですが、そのまま使うと「文章のテイストがブレる」「専門用語の使い方が統一されない」といった問題が起こりがちですよね。そこで私たちは、**取引先の文体やテーマに合わせたプロンプト**を開発し、

- 記事ジャンルごとの構成を固定化
- トンマナやキーワードを一括管理
- クライアントに合わせて表現を微調整

といった仕組みを整えました。このおかげで、**同じトーン＆マナーで質の良い記事**を安定して作れるようになっています。

### 自動反映機能の導入

記事を作って終わり、ではありません。次に待っているのが、**CMS への投稿やタグ付け、画像のアップロード**などの細かな作業です。  
ここを自動化するため、生成した記事を**ツール上から一気に HP へ反映できる機能**を作り込みました。今まではエクセルで管理してコピペしたり、手動で画像をアップしたりと大変だったところが、ワンクリックで済むようになったのです。

## ツールの概要：技術構成

私たちが開発したツールは、以下のような設計で動いています。

- **フロントエンド (Next.js + TypeScript)**
  - ブラウザ上で完結する管理画面を作り、操作しやすい UI を実現
  - カテゴリや文体をボタンひとつで切り替えられるよう工夫
- **サーバーサイド (Node.js + TypeScript)**
  - ChatGPT API と連携し、独自プロンプトを素早く反映
  - 生成した記事データを整理し、CMS へスムーズにつなぐブリッジ役
- **データベース (Firestore)**
  - 記事テンプレートや投稿スケジュール、ユーザー権限を一括管理
  - 担当者の作業進捗がすぐにわかるよう可視化

全体としては一般的な構成ですが、**プロンプト管理**と**自動反映機能**を組み合わせた部分がこのツールの強みです。

実際、この仕組みを導入してどうなったのか。取引先からは、こんな声をいただいています。
