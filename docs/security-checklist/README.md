# YOSHINANIセキュリティチェックリスト

SaaS・業務システム向けの共通120項目と、ISMS取得企業向けの追加20項目を公開しています。

| 資料 | 内容 |
|---|---|
| [Zenn記事](https://zenn.dev/yoshinani_dev/articles/756f59add7e761) | 作った背景、優先して見る項目、評価の進め方 |
| [詳細版](./checklist.md) | 全140項目の合格条件、確認方法、証跡例、参照元 |
| [評価記録テンプレート](./assessment-template.md) | 全140項目の担当、確認日、証跡、未達事項を記録する空欄の表 |

## 使い方

1. 評価対象のサービス、環境、データ、顧客、適用要求を決めます。
2. 詳細版と評価記録テンプレートを、社内の権限管理された場所へ複製します。
3. 適用する各項目を確認し、結果と証跡を記録します。初期状態はすべて未評価です。
4. ISMS取得企業では、自社の認証範囲、適用宣言書、社内規程を対応付けます。
5. 未達事項に担当と期限を設定し、再検証と受入判断を記録します。

実際の構成、脆弱性、証跡、顧客情報、社内文書、評価結果は公開リポジトリへ書き戻さないでください。
修正提案は汎用的な記述にし、セキュリティ上の問題を含む実システムの情報は公開Issueに記載しないでください。

## この表で示していること

この資料は、公開された国際基準を参照して独自に編集した実務用のテンプレートです。
規格本文の代替、認証取得、特定の会社・製品の適合や安全性を保証する資料ではありません。
優先度、頻度、期限は初期推奨です。適用法令、契約、自社のISMSで必要な条件を反映してください。
参照元は詳細版の各分野に記載しています。
